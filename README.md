# Next Chapter Guides website

Static site (no build step). Deployed on Vercel.

- `index.html` – the whole site. Edit `STORE` (prices + checkout links) and `NEWSLETTER` (sign-up form) near the bottom.
- `assets/` – product images, journey map, logo (SVG).
- `previews/` – public preview pages only. The full paid PDFs are NOT in this repo; they live with the checkout provider.
